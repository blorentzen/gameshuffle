## Instant Games ▸ Review: notes for the reviewer

> GameShuffle has three tabs.
>
> 1. Daily (opens first): tap "Start today's puzzle", type a character's name in the box and pick it from the list, then tap Guess. Each guess fills a row: green is a match, yellow is close, and arrows point higher or lower. A new hint appears after each miss. After 5 guesses there is one last chance that shows the first letter of the answer.
> 2. Dex: the same game with a different set of characters. After the first guess the list only shows names that still fit the clues; "Show all" lists everyone.
> 3. Chat Brain: answer today's survey question (answers are anonymous), then name the top answers on today's board. Three misses ends the board.
>
> After a daily, "Share with friends" shares a picture of the result: squares only, never the answer. The leaderboard is optional: a player picks a nickname to join, and we never ask for or use their Facebook name.
>
> There is no login and the game requests no Facebook permissions. It uses Zero Permissions to reach gameshuffle.co for the Chat Brain question and board and for the optional leaderboard. It never receives the player's Facebook ID, name or photo. Streaks and progress are saved in Instant Games player storage.
>
> The Daily Shuffle and Daily Dex answers are names of video game characters, with facts and hints we wrote ourselves. The game includes no artwork, logos or audio from those games. GameShuffle is not affiliated with Nintendo or The Pokémon Company.
>
> New puzzles arrive at midnight Pacific time.
